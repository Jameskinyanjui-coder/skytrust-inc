## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn or pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/Jameskinyanjui-coder/skytrust-inc.git
cd skytrust-inc

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.

## 🛠️ Tech Stack & Key Features

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Vanilla CSS Modules with custom design tokens
- **Icons**: Lucide React
- **SEO & Metadata**: Dynamic sitemap generation, structured JSON-LD schemas, OpenGraph & Twitter cards
- **Performance**: Zero external heavy UI library overhead, optimized font loading

## 📁 Project Structure

```text
sky-trust/
├── public/                # Static assets (logo, favicon, robots.txt)
├── src/
│   ├── app/               # Next.js App Router pages & metadata routes (sitemap.ts)
│   ├── components/        # UI Components
│   │   ├── common/        # Shared components (Logo, etc.)
│   │   ├── home/          # Home page sections (Hero, WhySkyTrust, ServicesGrid, etc.)
│   │   ├── layout/        # Header, Footer, CtaBanner
│   │   └── services/      # Service template components
│   └── lib/               # Data files & utility helper methods
```
